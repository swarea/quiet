# Assets

`mark.png` is the repository mark the README displays at 96×96, and
`mark-source.png` is the card it is cut from. `social1280.png` is the card GitHub
unfurls, generated by `scripts/make-social.html`, which draws `mark.png`.

The source is kept here so this repository can rebuild its own mark. The card set
it came from is not in any repository and has moved before, so depending on a
path outside version control would mean the mark could not be remade.

The shape is not a local choice. It follows
[the organization's mark rule](https://github.com/swarea/.github/blob/main/docs/repository-mark.md),
which also carries the generator that produces it.
