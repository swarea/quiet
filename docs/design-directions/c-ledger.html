TypeScript 프로젝트에서 런타임 검증이 필요한 순간들

2025.06.28 · swarea · 댓글 4

TypeScript는 컴파일 시점의 타입만 검증한다. API 응답, 폼 입력, URL 파라미터처럼 런타임에 들어오는 데이터는 타입 시스템의 보호 밖에 있다.

경계에서 검증하고, 내부에서는 신뢰한다.

스키마를 코드로 선언하기

응답 스키마를 선언하면 타입까지 함께 얻는다. 검증 로직과 타입 정의가 갈라질 수 없다는 것이 핵심 장점이다.

const User = z.object({
  id: z.number(),
  name: z.string().min(1),
  email: z.string().email(),
});
